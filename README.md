# swift-lint

Use this package to write lint rules for Swift source and to say which rules apply where. It defines rules, their composition and configuration, and the syntax facts rules read. It does not find files, parse them, resolve severities or run rules over a package; the runner that depends on this package does that. Start from `Lint.Rule`, a rule passed as a value. Its `observe` closure reads one `Lint.Source.Parsed` and returns a `Lint.Rule.Observation`. Then collect rules into a `Lint.Configuration`. Rule tests can depend on the `Lint Test Support` product.

## Laws

- **Observation.** Empty findings with `.measured` coverage mean the rule checked the file and found nothing. `.unmeasured` means the rule did not check it. `.inapplicable` means the rule does not apply to the file. `observe` receives the resolved severity and puts it on every finding. `Lint.Rule.measured` always reports `.measured` and `.applicable`.
- **Repair.** A rule built without a `repair` closure returns `.refused(.repairUnavailable)`.
- **Composition.** `filtered(toPaths:)`, `with(default:)` and `pinned(to:)` keep the rule's id, suppression and controls. `with(default:)` changes only the default; the severity passed to `observe` still wins. `pinned(to:)` ignores the severity passed to `observe`. A filtered rule gives no findings, `.measured` and `.inapplicable` on a path outside its filter, and its repair returns `.unchanged` there.
- **Combining.** `Lint.Rule.combining` observes its child rules in order and concatenates their findings. At the first `.unmeasured` child it stops, returns the findings collected so far and reports that child's reason. Later children are not observed. The result is `.applicable` if any observed child was. The combined rule takes the suppression and controls declared on it, never its children's, and it cannot repair.
- **Filter.** `Lint.Filter` matches plain string prefixes, not path components: `Sources/A` also matches `Sources/AB/x.swift`. An empty `included` list admits every path. Otherwise a path must start with one of the `included` prefixes. A path that starts with an `excluded` prefix is always rejected.
- **Configuration.** `rules.effective.entries` lists the parent's effective entries first, then this configuration's own. A later entry for the same `Lint.Rule.ID` replaces an earlier one but keeps the earlier one's position. Entries whose mode is `.disabled` are dropped. So is any ID in the `disabled` set at any level of the chain: the set is a union, and a child cannot re-enable an ID its parent disabled. `excluded` holds only this configuration's own paths and is not merged with the parent's. `.enable(_:paths:)` builds the filter into the stored rule.
- **Visibility.** A declaration's effective visibility is the narrowest of its own visibility and that of every enclosing declaration. `open` counts as `public`. A member with no modifier takes the modifier of its enclosing extension or protocol; otherwise it is `internal`. An extension with no modifier does not narrow its members.
- **Index.** Every type is recorded under both its qualified name and its last name component, and lookups fall back to the last component. Two types with the same short name in different namespaces therefore share facts. Inherited types are recorded by their last name component. Every actor conforms to `Actor`. `reachableProtocols(of:)` follows conformances transitively. A protocol's requirements are recorded by name: properties, methods and subscripts. Initializers are not recorded. `merge` takes the union of all facts and concatenates import lists recorded under the same path. Its `license` is the first one that is not `.unread`.
- **Imports.** Clauses are listed outermost first. A clause from `#elseif` or `#else`, or with a `!` anywhere in its condition, names no identifiers. Calls such as `canImport(X)` or `os(Linux)` contribute no identifiers. A `||` anywhere in the condition makes the clause something other than a conjunction. `imports(under:)` matches whole path components and returns the files sorted by path.
- **Brand.** `Lint.Brand.types(in:)` returns only the file's top-level type names, and it does not look inside a file-scope `#if`, so a type declared there is not returned. `Lint.Brand.owned` checks only the `types` the caller stored on `Lint.Source.Parsed`, so a source with no types stored is never owned.
- **Syntax.** `Lint.Syntax.Conditional` flattens every branch of every `#if`, recursively, whichever branch would compile. A type inside a file-scope `#if` is still top level for `Lint.Syntax.Scope.isTopLevel`. `Lint.Syntax.Identifier.unescaped` strips only a matched pair of backticks.
